# Media Logos

Place the logo images for each media outlet in this directory.

## Required Logo Files:

1. `inc42.png` - Inc42 logo
2. `free-press-journal.png` - Free Press Journal logo
3. `bw-disrupt.png` - BW Disrupt logo
4. `economic-times.png` - Economic Times logo
5. `vyapaar-jagat.png` - Vyapaar Jagat logo
6. `the-fearless-indian.png` - The Fearless Indian logo

## Logo Specifications:

- **Format**: PNG (with transparent background preferred)
- **Recommended dimensions**: 120x60px or higher resolution with same aspect ratio
- **File size**: Keep under 50KB for optimal web performance
- **Quality**: High-resolution logos that scale well

## Notes:

- Use the official brand logos from each media outlet
- Ensure you have rights/permission to use the logos
- Transparent backgrounds work best with the design
- The logos will be automatically resized to fit within 120x60px containers
