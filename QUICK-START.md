## 📐 Image Specs (Don't worry if not exact)

- **Format**: JPG or PNG
- **Hero/Team**: 600×700px (portrait)
- **Manifesto/GES**: 700×500px (landscape)  
- **Focus Areas**: 400×300px (landscape)
- **File size**: Under 500KB each (compress if needed)

**The CSS will automatically crop/resize**, so just use high-quality photos!
